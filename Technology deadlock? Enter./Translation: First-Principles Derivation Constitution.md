## Seven Postulates (Definitive · Hardened)

**1. Overhead Cannot Be Eliminated**
Any observation, judgment, prediction, or control action carries inherent latency and resource overhead; precision, overhead, and disturbance form a Pareto frontier and cannot be optimized infinitely and simultaneously. No zero-overhead chain exists.

**2. Resource Conservation**
Within a closed system, the total amount of effective resources is conserved; resources can only be transferred among subsystems, not generated or destroyed from nothing. Any module's resource occupation inevitably squeezes the available resources of other subsystems.

**3. Disturbance-Observation Coupling**
The act of observation itself introduces disturbance; disturbance cannot be completely eliminated, only decoupled, isolated, suppressed, or radius-compressed. No prediction scheme exists that covers 100% of all disturbances; confidence has a natural lower bound.

**4. Causal-Temporal Irreversibility**
Feedback can only act on observation results that have already occurred; prediction carries an inherent temporal offset upper bound; causality cannot be reversed. If the temporal offset exceeds the intrinsic threshold, the action fails.

**5. Layered Isolation**
The critical control path permits only low-overhead lightweight computation; high-fidelity simulation, full-spectrum inversion, and heavy fitting must be placed in the offline background, with distilled simplified parameters dispatched downstream. Embedding heavy computation into the real-time critical path is forbidden. Violators are judged as collapsed.

**6. Collapse Adjudication Law**
If any metric breaches the intrinsic threshold for this scenario, or violates any of the foregoing postulates, the configuration is judged as causally collapsed. The only lawful action after judgment: discard the current configuration and return to first principles for reconstruction. It is forbidden to modify thresholds, add verbal buffers, use compromise rhetoric to conceal collapse, or postpone judgment with "tool pending revision." Adjudication authority belongs to physics, not to humans.

**7. Feature Drift and Confidence Decay**
System features continuously drift with wear, fatigue, ablation, and aging; model confidence decays as feature drift continues. When confidence falls below the threshold, the model must be downweighted and switched to a reactive fallback mechanism. The fallback criterion must be an observable physical failure mode, not model self-assessment.
